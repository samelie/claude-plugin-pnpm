# Evidence contracts

Read for research findings, assessment synthesis and review. Apply to decisive claims; do not turn incidental observations into a full audit.

| Claim | Required evidence |
|---|---|
| Current absence or non-delivery | Exact proposition; searched roots and command/method; revision or as-of time; result and boundary; plausible refuter. Distinguish "source reports absent" from current verification. A failed/unavailable query establishes no absence. |
| Ambiguous product noun | Define from its authoritative source before choosing search terms. A customer-account profile cannot settle whether an entity-history profile exists. |
| Measurement | Value, unit, attribution dimensions, aggregation/window and storage shape. Per-invocation JSONL timing cannot establish persisted per-source minutes. |
| Readiness or delivery blocker | State the milestone: internal rehearsal, first customer proof, or scaled product. Check permitted interim/manual delivery paths before calling missing scale infrastructure a first-customer blocker. No customer contact is authorized by this analysis. |
| Source citation | Resolvable path plus exact line/section/finding locator. Preserve provenance through synthesis; never invent an ID or shorten a path into ambiguity. |

Load-bearing negatives receive the existing independent refutation pass: try alternative implementations/roots rather than repeating the same search. A generic invalidated question premise needs evidence. Reopening a registered map premise additionally requires its `P-*` ID, linked decision and lifecycle update; do not invent a map strike for every caveat.

Before declaring a named path absent, check that exact path and resolve any symlink. An index or file listing that excludes hidden paths or does not follow symlinks cannot establish absence of a skill projection.

Citation verification first counts the actual inspected references and rejects an empty set when citations are required. Then check paths and locators; independently sample whether sources support the claim. File existence alone does not establish semantic support.

Before targeting tests, inspect the nearest package script and underlying runner's argument forwarding. Record the exact command and actual executed suites/tests/skips; passing an unintentionally broad suite is broad evidence, not a targeted test. Follow the pnpm-workspace-filter skill for package routing.
